# Japanese Trust Strip Caption Design

## Scope

Redesign only the four-item trust strip immediately below the Japanese homepage hero. Preserve all four existing statements and their order. Do not add a section heading, kicker, card title, link, image, or new content.

## Visual Direction

Use a quiet museum-caption treatment that fits the existing monochrome Swiss/editorial system. Keep the background white. Avoid rounded corners, shadows, filled cards, decorative color, and oversized promotional typography.

## Desktop Layout

- Display the four entries in one equal-width row.
- Add a small `01` through `04` index to each entry.
- Separate entries with fine vertical rules and define the strip with fine horizontal rules.
- Use restrained spacing and a clear hierarchy between index, primary credential or activity, and its supporting line.
- Keep alignment consistent so the section reads as one composed information band rather than four independent cards.

## Mobile Layout

- Display the entries in a two-column grid.
- Preserve the same index and typographic hierarchy.
- Use horizontal and vertical rules to maintain the caption-grid structure.
- Ensure text wraps naturally without clipping and retains comfortable touch-independent spacing.

## Constraints

- Do not add `BACKGROUND / PRACTICE` or any other section label.
- Do not alter the hero, CTA links, header, or sections below the trust strip.
- Preserve accessibility and responsive behavior.
- Retain the existing black, white, and neutral-gray palette.

## Verification

- Confirm all four entries remain present and in the same order.
- Confirm the desktop layout is four columns and the mobile layout is two columns.
- Confirm no horizontal overflow at mobile width.
- Run the existing test suite and inspect the local preview at desktop and mobile widths.
