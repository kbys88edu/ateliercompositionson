# Comparaison — page d'accueil française

Date : 2026-07-11

## Avant / après

| Point | Avant | Après |
| --- | --- | --- |
| Rôle de la page | Présenter en détail chaque offre | Aider à choisir une entrée ou réserver |
| Sections de lecture principales | Hero + 10 sections | Hero + 8 sections + footer |
| Contenu visible | Disciplines, diagnostic, formats, tarifs, conditions et contact répétés | Entrées, processus, pratique, format, échange, ressources, FAQ |
| CTA vers booking | Répété dans le hero, formats et contact | Hero, format et section dédiée |
| Distance hero → tarif | Plusieurs sections | Le tarif est visible dans le hero et détaillé après trois sections courtes |
| Mobile | Diaporama puis de nombreux blocs similaires | CTA, tarif puis trois choix distincts |
