# Voice sample folders

Female:
C4.wav, G4.wav, C5.wav, G5.wav

Male:
C2.wav, G2.wav, C3.wav, G3.wav, C4.wav, G4.wav

Playback behavior:
- Soprano / female samples are played one octave lower.
- Written G4 uses female/G4.wav with playbackRate 0.5.
- Written C5 uses female/C5.wav with playbackRate 0.5.
- Bass / male samples are not octave-transposed.
