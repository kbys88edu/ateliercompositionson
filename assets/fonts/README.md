# TeX Gyre Heros Regular

Unmodified OpenType font from the TeX Gyre collection (Heros 2.004).

- Project: https://ctan.org/pkg/tex-gyre-heros
- Download: https://mirrors.mit.edu/CTAN/fonts/tex-gyre/opentype/texgyreheros-regular.otf
- Maintainers: Bogusław Jackowski and Janusz Marian Nowacki

Used for the Atelier Composition Son brand name. Canvas previews embed the same font file to make the preview independent of production deployment.
