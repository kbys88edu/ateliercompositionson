Données collectées

Le formulaire peut recueillir votre nom, votre adresse e-mail, la langue souhaitée, le domaine principal, votre fuseau horaire ou vos disponibilités, un message court et, si vous choisissez de le transmettre, un lien vers un projet.

La réservation via Calendly peut recueillir les informations nécessaires au choix et à la confirmation d’un rendez-vous selon les paramètres du service.

Les champs marqués d’un astérisque dans le formulaire sont nécessaires pour traiter la demande. Le lien vers une œuvre ou un document est facultatif.
